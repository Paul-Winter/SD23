Семейства шрифтов (font-family):

serif - шрифты с засечками (Times New Roman)

sans-serif - шрифты без засечек (Arial)

monospace - моноширинные шрифты (Consolas, Courier New)

cursuve - курсивные шрифты (ComicSans MS)

fantasy - фантазийные или декоративные шрифты (Impact)
