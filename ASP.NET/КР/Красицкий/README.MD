DOTs - Data Transfer Objects
Сделал для безопасности данных с работой из бд, вот выписка:
Это простые классы, которые используются для передачи данных между различными слоями приложения (например, между API/Контроллером и клиентом, или между Сервисом и Контроллером).

Если вам понадобиться сделать реквесть запрос апи то не забывайте для безопасности через дотс проводить. А так все апи можно глянуть в /api
