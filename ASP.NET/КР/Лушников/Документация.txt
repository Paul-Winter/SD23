ДОКУМЕНТАЦИЯ ПРОЕКТА STAVZOO
============================


НАЗНАЧЕНИЕ
----------

StavZoo — это веб-приложение на ASP.NET Core Razor Pages, представляющее
страницу животного Ставропольского зоопарка в парке Победы. В качестве
основного обитателя выбрана львица Киара — она стала матерью троих львят
в мае 2025 года. Приложение позволяет посетителям ознакомиться с
информацией о животном, посмотреть фото, видео и веб-камеру, а также
отправить донат на корм и лечение. Сотрудники зоопарка могут вести дневник
наблюдений, загружать новые фотографии и управлять донатами.


ТЕХНОЛОГИЧЕСКИЙ СТЕК
-------------------

Проект построен на платформе .NET 10 с использованием ASP.NET Core Razor
Pages для серверной генерации страниц и API-контроллеров для программного
доступа к данным. В качестве ORM используется Entity Framework Core, база
данных — SQLite (файл StavZoo.db хранится в папке проекта). Аутентификация
выполнена через JWT-токены, которые сохраняются в HttpOnly-Cookie. Пароли
пользователей хешируются библиотекой BCrypt.Net-Next. Фронтенд написан на
HTML5, CSS3 и Razor без использования внешних JS-фреймворков.


СТРУКТУРА ПРОЕКТА
-----------------

В папке Controllers лежат два API-контроллера: AuthController для входа и
выдачи JWT-токена, LionApiController для доступа к данным животного и
дневника. В папке Data находится контекст базы данных ZooDbContext.
В папке Models четыре сущности: Lion (животное), LionDiaryEntry (запись
дневника), User (пользователь) и Donation (донат). В папке Pages —
Razor-страницы: главная, страница входа, регистрации, а также вложенная
папка Lion со страницами Index (страница животного) и Diary (дневник).
В папке Services лежит JwtService для генерации токенов. В wwwroot
находятся стили CSS и загруженные фотографии в папке images/lion.
Файл Program.cs — точка входа, appsettings.json — конфигурация.


МОДЕЛЬ ДАННЫХ
-------------

Сущность Lion содержит идентификатор, имя животного, латинский slug для
URL, текстовое описание, ссылки на три главных фото (PhotoUrl, PhotoUrl2,
PhotoUrl3), ссылки на видео и веб-камеру, дату рождения и имя матери.

Сущность LionPhoto хранит ссылки на дополнительные фото в галерее.

Сущность LionDiaryEntry содержит идентификатор, внешний ключ на животное,
тип записи (Кормление, Спаривание, Потомство, Здоровье, Наблюдение,
Ветеринарный осмотр), текст заметки, дату и время записи и автора.

Сущность User содержит идентификатор, логин, хеш пароля и роль. Роль может
быть Visitor (посетитель) или Zookeeper (сотрудник).

Сущность Donation содержит идентификатор, внешний ключ на животное, сумму
в рублях и дату внесения.


МАРШРУТЫ
--------

Главная страница доступна по адресу "/" и открыта всем.
Страница животного — "/stav-zoo/{slug}" (например, /stav-zoo/kiara).
Дневник — "/stav-zoo/{slug}/diary", доступен только для роли Zookeeper.
Вход — "/login", регистрация — "/register".
API — "/api/lion/{slug}", "/api/lion/{slug}/diary", "/api/auth/login".


РОЛИ И ПРАВА
------------

Посетитель (Visitor) может просматривать главную страницу и страницы
животных, отправлять донаты, смотреть фото, видео и веб-камеру,
регистрироваться и входить в систему.

Сотрудник (Zookeeper) имеет все права посетителя плюс доступ к дневнику
(добавление, редактирование, удаление записей), возможность загружать
и удалять фото, а также управлять донатами — просмотр истории,
редактирование суммы, удаление отдельных донатов и полную очистку списка.


ВХОД В ДНЕВНИК — ВАЖНО
---------------------

Чтобы открыть записи дневника животного, нужно войти в аккаунт сотрудника
зоопарка (роль Zookeeper). Дневник недоступен для обычных посетителей.

ПО УМОЛЧАНИЮ ПРИ ПЕРВОМ ЗАПУСКЕ ПРИЛОЖЕНИЯ АВТОМАТИЧЕСКИ
СОЗДАЁТСЯ СЛЕДУЮЩИЙ АККАУНТ СОТРУДНИКА:

    Логин:  keeper
    Пароль: 123
    Роль:   Сотрудник (Zookeeper)

ПОШАГОВАЯ ИНСТРУКЦИЯ:

1. Откройте страницу входа:  /login
   Или перейдите по ссылке "Вход" в верхнем меню сайта.

2. Введите в поля:
       Имя пользователя:  keeper
       Пароль:            123

3. Нажмите кнопку "Войти".

4. После входа вы автоматически получите роль Zookeeper — сотрудник
   зоопарка. В верхней части страницы исчезнет форма входа, а на странице
   животного появятся:
       - форма загрузки новых фотографий;
       - кнопки "Удалить" под каждым фото в галерее;
       - таблица всех донатов с возможностью редактирования и удаления;
       - доступ к редактированию дневника.

5. Откройте дневник по ссылке "📖 Дневник (для сотрудников)" на странице
   животного, или введите адрес вручную:

       https://localhost:7285/stav-zoo/kiara/diary

6. В дневнике вы увидите:
       - форму добавления новой записи (тип записи, автор, заметка);
       - кнопки-фильтры по типам записей (Все, Кормление, Спаривание,
         Потомство, Здоровье, Наблюдение, Ветеринарный осмотр);
       - таблицу всех существующих записей с кнопками "Редактировать"
         и "Удалить" для каждой записи.

ПРИМЕЧАНИЕ: Если вы хотите зарегистрировать нового сотрудника —
используйте страницу /register и выберите роль "Сотрудник". После
регистрации войдите под новым логином и паролем.


ОСНОВНЫЕ ФУНКЦИИ
----------------

На главной странице отображается приветственный блок с информацией о
зоопарке, три отдельные карточки с фотографиями Киары и краткая
статистика: количество животных в базе, сумма собранных донатов и год
основания зоопарка. Ниже — история зоопарка и ссылки для входа и
регистрации. В верхнем меню есть ссылка на официальный сайт зоопарка —
https://zoostav.ru.

Страница льва показывает фотографию животного, галерею из нескольких
фото, историю особи, основные факты (дата рождения, мать, отец, вес
львят, рацион), видео с Rutube-плеером, блок веб-камеры и форму доната.
Для авторизованных сотрудников дополнительно отображается форма загрузки
фото и таблица всех донатов с кнопками управления.

Регистрация позволяет создать нового пользователя с выбранной ролью
("Посетитель" или "Сотрудник") и паролем. Пароль хешируется через BCrypt.
Вход проверяет логин и пароль, при успехе выдаёт JWT-токен и сохраняет
его в Cookie.

Дневник позволяет сотруднику добавлять записи о кормлении, спаривании,
потомстве, здоровье, наблюдении и ветеринарном осмотре. Каждую запись
можно отредактировать или удалить. Записи фильтруются по типам. Все
действия фиксируются с указанием даты и автора.

Управление донатами доступно только сотрудникам на странице льва.
Отображается таблица всех донатов с датой и суммой. Каждый донат можно
отредактировать или удалить, а также можно очистить весь список
одной кнопкой.


АУТЕНТИФИКАЦИЯ И АВТОРИЗАЦИЯ
----------------------------

JWT-токен генерируется в сервисе JwtService. Внутри токена хранятся два
claim-а: имя пользователя и его роль. Срок жизни токена — 8 часов.
Алгоритм подписи — HMAC SHA-256.

Токен сохраняется в Cookie с именем access_token. Cookie помечена как
HttpOnly (недоступна из JavaScript), Secure (передаётся только по HTTPS)
и SameSite=Lax (отправляется при навигации внутри сайта).

При каждом запросе ASP.NET Core читает токен из Cookie. Это настроено
в Program.cs через событие OnMessageReceived в JwtBearerEvents.

Защита страниц выполняется через атрибут [Authorize(Roles = "Zookeeper")].
Так защищён класс DiaryModel — дневник доступен только сотрудникам.


КОНФИГУРАЦИЯ
------------

В appsettings.json хранится строка подключения к базе данных и параметры
JWT: секретный ключ и имя издателя. База данных — SQLite, файл StavZoo.db
лежит в корне проекта. Ключ JWT должен быть длинным (не менее 32
символов), в реальном проекте его хранят в секретах или переменных
окружения.


ИНИЦИАЛИЗАЦИЯ БАЗЫ ДАННЫХ
-------------------------

При первом запуске приложения в Program.cs выполняется несколько
действий. Метод EnsureCreated создаёт базу данных и все таблицы по
моделям. Проверяется наличие папки wwwroot/images/lion — если её нет,
она создаётся. Если таблица Lions пуста, добавляется львица Киара с
тремя главными фото, 5 фото в галерею и ссылкой на видео. Если таблица
Users пуста, создаётся пользователь keeper с паролем 123 и ролью
Zookeeper (см. раздел "ВХОД В ДНЕВНИК"). Если таблица LionDiaryEntries
пуста, добавляются 4 стартовые заметки от зоологов. При следующих
запусках данные не пересоздаются.


ЗАПУСК ПРОЕКТА
--------------

Для работы нужна Visual Studio 2022 или новее с установленным компонентом
"ASP.NET и веб-разработка", а также .NET 10 SDK. SQL Server не требуется —
используется SQLite. Порядок запуска:

1. Открыть файл StavZoo.slnx.
2. Дождаться восстановления NuGet-пакетов.
3. В окне Developer PowerShell выполнить команду:

       dotnet dev-certs https --trust

   и подтвердить установку сертификата (нажать "Да").

4. Нажать F5. Браузер откроется автоматически.

Для входа в аккаунт сотрудника: логин keeper, пароль 123.


РАБОТА С БАЗОЙ ДАННЫХ
---------------------

База данных — файл StavZoo.db в корне проекта. Для просмотра и
редактирования можно использовать бесплатную программу DB Browser for
SQLite (sqlitebrowser.org). В ней открываются таблицы Lions,
LionDiaryEntries, LionPhotos, Users и Donations.


ЗАГРУЗКА ФОТО
-------------

Сотрудник выбирает файл на странице льва, нажимает "Загрузить". Сервер
сохраняет файл в папку wwwroot/images/lion с уникальным GUID-именем, а
путь записывает в базу данных. При следующем открытии страницы фото
отображается в галерее. Сотрудник может удалить любое фото из галереи —
кнопка "Удалить" под каждой картинкой.


ВСТРАИВАНИЕ ВИДЕО
-----------------

Для видео используется встроенный плеер Rutube через iframe. Ссылка вида
https://rutube.ru/play/embed/XXXX/ сохраняется в поле VideoUrl в базе
данных. Плеер адаптивен: контейнер с пропорцией 16:9 масштабируется под
ширину экрана. Для воспроизведения нужен доступ к интернету.


РЕАЛЬНЫЙ ДОНАТ
--------------

На странице льва есть две опции для донатов:

1. Форма "Отправить донат" — сохраняет сумму в базу данных (демонстрация
   работы с БД).

2. Кнопка "Реальный донат через CloudTips" — ведёт на страницу сбора
   https://pay.cloudtips.ru/p/2e7c4e19, где можно оплатить через Сбер,
   СБП или банковскую карту.

ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
----------------------------

Если при открытии главной страницы возвращается 404 — проверьте, что в
файле Pages/Index.cshtml первая строка @page (без пути).

Если 404 на странице животного — проверьте, что в Pages/Lion/Index.cshtml
первая строка @page "/stav-zoo/{animalName}".

Если база данных не создаётся — проверьте права на папку проекта.

Ошибка сертификата — выполните dotnet dev-certs https --trust.

Если фото не отображается — проверьте наличие файлов в папке
wwwroot/images/lion.

Если видео не грузится — проверьте доступ к интернету и к сайту rutube.ru.

Если дневник не открывается — убедитесь, что вы вошли в аккаунт с ролью
Zookeeper (логин keeper, пароль 123).


API — ПРИМЕРЫ
-------------

Получить данные животного:

    GET https://localhost:7285/api/lion/kiara

Получить JWT-токен:

    POST https://localhost:7285/api/auth/login
    Параметры: username=keeper, password=123

Получить дневник (требуется токен):

    GET https://localhost:7285/api/lion/kiara/diary
    Заголовок: Authorization: Bearer <токен>


ДАЛЬНЕЙШЕЕ РАЗВИТИЕ
-------------------

Проект можно улучшить несколькими способами. Добавить других животных
(тигр, медведь) — просто новые записи в БД. Сделать админ-панель для
управления животными. Подключить настоящую веб-камеру. Добавить график
динамики донатов. Настроить экспорт дневника в PDF. Использовать
миграции EF Core вместо EnsureCreated. Разместить проект на хостинге
для доступа из интернета.
