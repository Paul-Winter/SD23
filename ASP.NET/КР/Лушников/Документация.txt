ДОКУМЕНТАЦИЯ ПРОЕКТА STAVZOO
============================


НАЗНАЧЕНИЕ
----------

StavZoo — это веб-приложение на ASP.NET Core Razor Pages, представляющее 
страницу животного Ставропольского зоопарка в парке Победы. В качестве 
основного обитателя выбрана львица Киара — она стала матерью троих львят 
в мае 2025 года. Приложение позволяет посетителям ознакомиться с 
информацией о животном, посмотреть фото, видео и веб-камеру, а также 
отправить донат на корм и лечение. Сотрудники зоопарка могут вести дневник 
наблюдений, загружать новые фотографии и управлять донатами.


ТЕХНОЛОГИЧЕСКИЙ СТЕК
-------------------

Проект построен на платформе .NET 10 с использованием ASP.NET Core Razor 
Pages для серверной генерации страниц и API-контроллеров для программного 
доступа к данным. В качестве ORM используется Entity Framework Core, база 
данных — SQL Server LocalDB. Аутентификация выполнена через JWT-токены, 
которые сохраняются в HttpOnly-Cookie. Пароли пользователей хешируются 
библиотекой BCrypt.Net-Next. Фронтенд написан на HTML5, CSS3 и Razor без 
использования внешних JS-фреймворков.


СТРУКТУРА ПРОЕКТА
-----------------

В папке Controllers лежат два API-контроллера: AuthController для входа и 
выдачи JWT-токена, LionApiController для доступа к данным животного и 
дневника. В папке Data находится контекст базы данных ZooDbContext. 
В папке Models четыре сущности: Lion (животное), LionDiaryEntry (запись 
дневника), User (пользователь) и Donation (донат). В папке Pages — 
Razor-страницы: главная, страница входа, регистрации, а также вложенная 
папка Lion со страницами Index (страница животного) и Diary (дневник). 
В папке Services лежит JwtService для генерации токенов. В wwwroot 
находятся стили CSS и загруженные фотографии в папке images/lion. 
Файл Program.cs — точка входа, appsettings.json — конфигурация.


МОДЕЛЬ ДАННЫХ
-------------

Сущность Lion содержит идентификатор, имя животного, латинский slug для 
URL, текстовое описание, ссылки на фото, видео и веб-камеру, дату рождения 
и имя матери. Также есть навигационное свойство — список записей дневника.

Сущность LionDiaryEntry содержит идентификатор, внешний ключ на животное, 
тип записи (кормление, спаривание, потомство, здоровье), текст заметки, 
дату и время записи и логин сотрудника, который её внёс.

Сущность User содержит идентификатор, логин, хеш пароля и роль. Роль может 
быть Visitor (посетитель) или Zookeeper (сотрудник).

Сущность Donation содержит идентификатор, внешний ключ на животное, сумму 
в рублях и дату внесения.


МАРШРУТЫ
--------

Главная страница доступна по адресу "/" и открыта всем. Страница животного 
— по адресу "/stav-zoo/{slug}", где slug — латинский идентификатор, 
например kiara. Дневник доступен по адресу "/stav-zoo/{slug}/diary" только 
для роли Zookeeper. Вход — "/login", регистрация — "/register". API 
доступен по адресам "/api/lion/{slug}" (публично), "/api/lion/{slug}/diary" 
(только Zookeeper) и "/api/auth/login" (публично, POST).


РОЛИ И ПРАВА
------------

Посетитель (Visitor) может просматривать главную страницу и страницы 
животных, отправлять донаты, смотреть фото, видео и веб-камеру, 
регистрироваться и входить в систему.

Сотрудник (Zookeeper) имеет все права посетителя плюс доступ к дневнику 
(добавление, редактирование, удаление записей), возможность загружать 
фото животного, а также управление донатами — просмотр истории, 
редактирование суммы, удаление отдельных донатов и полную очистку списка.


ОСНОВНЫЕ ФУНКЦИИ
----------------

На главной странице отображается приветственный блок с информацией о 
зоопарке, карточки всех животных с фотографиями и краткая статистика: 
количество животных в базе, сумма собранных донатов и год основания 
зоопарка. Ниже — история зоопарка и ссылки для входа и регистрации.

Страница льва показывает фотографию животного, историю особи, основные 
факты (дата рождения, мать, отец, вес львят, рацион), видео с 
Rutube-плеером, блок веб-камеры и форму доната. Для авторизованных 
сотрудников дополнительно отображается форма загрузки фото и таблица 
всех донатов с кнопками управления.

Регистрация позволяет создать нового пользователя с выбранной ролью 
и паролем. Пароль хешируется через BCrypt. Вход проверяет логин и пароль, 
при успехе выдаёт JWT-токен и сохраняет его в Cookie.

Дневник позволяет сотруднику добавлять записи о кормлении, спаривании, 
потомстве и здоровье животного. Каждую запись можно отредактировать 
или удалить. Все действия фиксируются с указанием даты и логина автора.

Управление донатами доступно только сотрудникам на странице льва. 
Отображается таблица всех донатов с датой и суммой. Каждый донат можно 
отредактировать или удалить, а также можно очистить весь список 
одной кнопкой.


АУТЕНТИФИКАЦИЯ И АВТОРИЗАЦИЯ
----------------------------

JWT-токен генерируется в сервисе JwtService. Внутри токена хранятся два 
claim-а: имя пользователя и его роль. Срок жизни токена — 8 часов. 
Алгоритм подписи — HMAC SHA-256.

Токен сохраняется в Cookie с именем access_token. Cookie помечена как 
HttpOnly (недоступна из JavaScript), Secure (передаётся только по HTTPS) 
и SameSite=Lax (отправляется при навигации внутри сайта).

При каждом запросе ASP.NET Core читает токен из Cookie. Это настроено 
в Program.cs через событие OnMessageReceived в JwtBearerEvents.

Защита страниц выполняется через атрибут [Authorize(Roles = "Zookeeper")]. 
Так защищён класс DiaryModel — дневник доступен только сотрудникам.


КОНФИГУРАЦИЯ
------------

В appsettings.json хранится строка подключения к базе данных и параметры 
JWT: секретный ключ и имя издателя. Строка подключения указывает на 
LocalDB и базу StavZooDb. Ключ JWT должен быть длинным (не менее 32 
символов), в реальном проекте его хранят в секретах или переменных 
окружения.


ИНИЦИАЛИЗАЦИЯ БАЗЫ ДАННЫХ
-------------------------

При первом запуске приложения в Program.cs выполняется несколько 
действий. Метод EnsureCreated создаёт базу данных и все таблицы 
по моделям. Проверяется наличие папки wwwroot/images/lion — если её нет, 
она создаётся. Если таблица Lions пуста, добавляется львица Киара с slug 
kiara и заполненным описанием. Если таблица Users пуста, создаётся 
пользователь keeper с паролем 123 и ролью Zookeeper. При следующих 
запусках данные не пересоздаются.


ЗАПУСК ПРОЕКТА
--------------

Для работы нужна Visual Studio 2022 или новее с установленным компонентом 
"ASP.NET и веб-разработка", а также .NET 10 SDK и SQL Server LocalDB. 
Порядок запуска: открыть файл StavZoo.sln, дождаться восстановления 
NuGet-пакетов, в окне Developer PowerShell выполнить команду 
"dotnet dev-certs https --trust" и подтвердить установку сертификата, 
нажать F5. Браузер откроется автоматически. Учётные данные по умолчанию: 
логин keeper, пароль 123.


РАБОТА С БАЗОЙ ДАННЫХ
---------------------

Через меню "Вид — Обозреватель объектов SQL Server" можно открыть базу 
StavZooDb, просмотреть таблицы Lions, LionDiaryEntries, Users и Donations. 
Правой кнопкой по таблице вызывается "Просмотреть данные", правой кнопкой 
по базе — "Создать запрос" для выполнения SQL-команд.


ЗАГРУЗКА ФОТО
-------------

Сотрудник выбирает файл на странице льва, нажимает "Загрузить". Сервер 
сохраняет файл в папку wwwroot/images/lion с уникальным GUID-именем, 
а путь вида /images/lion/<имя>.jpg записывает в поле PhotoUrl. При 
следующем открытии страницы фото отображается над описанием. Папка 
wwwroot/images/lion включается в архив проекта, поэтому все загруженные 
фото переносятся вместе с ним.


ВСТРАИВАНИЕ ВИДЕО
-----------------

Для видео используется встроенный плеер Rutube через iframe. Ссылка 
вида https://rutube.ru/play/embed/XXXX/ сохраняется в поле VideoUrl 
в базе данных. Плеер адаптивен: контейнер с пропорцией 16:9 
масштабируется под ширину экрана.


ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
----------------------------

Если при открытии главной страницы возвращается 404, значит в файле 
Pages/Index.cshtml отсутствует директива @page без пути. Если 404 
на странице животного — проверьте, что в Pages/Lion/Index.cshtml первая 
строка @page "/stav-zoo/{animalName}". Если база данных не создаётся — 
убедитесь, что LocalDB запущен командой sqllocaldb start MSSQLLocalDB. 
Ошибка сертификата решается командой dotnet dev-certs https --trust. 
Если фото не отображается — проверьте наличие файла в wwwroot/images/lion 
и правильность пути в базе. Если видео не грузится — нужен доступ 
к интернету.


ПЕРЕДАЧА ПРОЕКТА НА ДРУГОЙ КОМПЬЮТЕР
------------------------------------

Перед архивированием закройте Visual Studio. Удалите из папки проекта 
временные каталоги bin, obj и .vs. Правой кнопкой по папке проекта 
выберите "Отправить — Сжатая ZIP-папка". Передайте архив пользователю.

На другом компьютере нужно установить Visual Studio 2022 с компонентом 
ASP.NET, распаковать архив, открыть StavZoo.sln, в Developer PowerShell 
выполнить dotnet dev-certs https --trust, нажать F5. Приложение 
запустится, база данных создастся автоматически, Киара и пользователь 
keeper добавятся. Все фото подхватятся из архива, видео будет работать 
при наличии интернета.


API — ПРИМЕРЫ
-------------

Получить данные животного можно запросом GET на 
https://localhost:7285/api/lion/kiara. Ответ придёт в формате JSON 
с полями id, name, slug, description и другими.

Получить JWT-токен можно запросом POST на 
https://localhost:7285/api/auth/login с параметрами username и password. 
Ответ содержит поле token.

Получить дневник можно запросом GET на 
https://localhost:7285/api/lion/kiara/diary с заголовком 
Authorization: Bearer <токен>. Без токена вернётся 401 Unauthorized.


ДАЛЬНЕЙШЕЕ РАЗВИТИЕ
-------------------

Проект можно улучшить несколькими способами. Хранить фото в облаке 
(Azure Blob Storage или S3) вместо локальной папки — это позволит 
развернуть приложение на хостинге, где файловая система только для 
чтения. Использовать миграции EF Core вместо EnsureCreated для 
безопасного обновления схемы. Подключить Swagger для документации API. 
Сделать админ-панель для добавления новых животных. Добавить логирование 
действий сотрудников. Настроить отправку уведомлений о новых донатах. 
Интегрировать платёжные системы для реального приёма денег.

---------

Учебный проект по веб-разработке на ASP.NET Core Razor Pages. Тема —
