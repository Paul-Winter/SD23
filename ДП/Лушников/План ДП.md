# План разработки веб-платформы для онлайн-продаж (Маркетплейс) с мультимодальной доставкой

## 🛠 Выбор технологического стека (Рекомендация)
*   **Среда разработки:** Visual Studio (2026 Community).
*   **Язык и фреймворк:** C# / ASP.NET Core MVC или ASP.NET Core Web API (с разделением на backend и frontend).
*   **База данных:** MS SQL Server или PostgreSQL.
*   **ORM:** Entity Framework Core (EF Core).
*   **Frontend:** HTML, CSS, JavaScript, Bootstrap или React/Vue.
*   **Архитектура:** MVC или Чистая архитектура (Clean Architecture).
*   **Дополнительно для логистики:** SignalR, интеграция с погодными API, интеграция с «ЭРА-ГЛОНАСС».

## Этап 1: Аналитика и проектирование (Фундамент)
1.  **Роли пользователей:** Покупатель, Продавец, Администратор, Оператор БАС (беспилотных авиационных систем), Диспетчер логистики, Водитель/курьер наземной доставки.
2.  **Целевые регионы:** Республика Саха (Якутия) — 641 населённый пункт (248 без дорог с твёрдым покрытием); Чукотский АО — 46 населённых пунктов (67% с населением менее 500 чел., плотность 0,07 чел/км²).
3.  **Мультимодальная модель доставки:**
    *   Наземная круглогодичная (дороги с твёрдым покрытием).
    *   Наземная сезонная (зимники).
    *   Воздушная БАС (самолётного и вертолётного/мультироторного типа).
    *   Комбинированная (наземный участок до взлёта + БАС).
4.  **База данных (ER-диаграмма):** Users, Roles, Shops, Categories, Products, Orders, Reviews, Payments. Таблицы логистики: DeliveryMethods, DeliveryZones, GroundRoutes, WinterRoads, DroneRoutes, DroneFlights, WeatherRestrictions, DeliveryOperators, DeliveryStatusHistory.
5.  **Макеты UI/UX:** Главная, каталог, товар, корзина, личные кабинеты, панель диспетчера, панель оператора БАС.

## Этап 2: Настройка проекта в Visual Studio
1.  Создание нового проекта ASP.NET Core Web App (MVC).
2.  Подключение EF Core и настройка строки подключения.
3.  Настройка Identity (с поддержкой всех ролей).
4.  Инициализация Git-репозитория.

## Этап 3: Разработка Backend (Серверная часть)
1.  Создание моделей данных (Models) и контекста БД (DbContext).
2.  Создание миграций (Add-Migration → Update-Database).
3.  Разработка сервисов:
    *   ProductService, OrderService.
    *   DeliveryRouterService (определяет доступные способы доставки по сезону и погоде).
    *   GroundLogisticsService (зимники, весогабаритный контроль).
    *   DroneLogisticsService (погодные условия, «ЭРА-ГЛОНАСС», дальность).
    *   OperatorService, WeatherService.
4.  Написание контроллеров и API-эндпоинтов.

## Этап 4: Разработка Frontend (Клиентская часть)
1.  Вёрстка страниц (Главная, Каталог, Товар, Корзина, Личный кабинет).
2.  Панели диспетчера логистики и оператора БАС.
3.  Динамика (JavaScript): AJAX для корзины, автодополнение поиска, динамический пересчёт доставки.

## Этап 5: Ключевой функционал (MVP)
1.  Регистрация и вход (все 6 ролей).
2.  Добавление товаров продавцом (с весом и габаритами).
3.  Справочник населённых пунктов и доступных способов доставки.
4.  Корзина и оформление заказа (статусы: «Ожидает погоды» → «Запланирован полёт/рейс» → «В пути» → «Доставлен»/«Возврат»).
5.  Создание маршрутов администратором.

## Этап 6: Продвинутый функционал (После MVP)
1.  Загрузка изображений (wwwroot или облако).
2.  Интеграция платежей (ЮKassa, Тинькофф, Stripe).
3.  Отзывы и рейтинги, чат (SignalR), Email/push-уведомления.
4.  Интеграция с погодными API и панель диспетчера с картой дронов в реальном времени.
5.  Страхование груза, интеграция с «ЭРА-ГЛОНАСС», мониторинг зимников.

## Этап 7: Тестирование и Развертывание
1.  Unit-тесты для ключевых сервисов (xUnit/NUnit).
2.  Проверка безопасности (SQLi, XSS, CSRF).
3.  Хостинг (VPS, Azure, Yandex Cloud).
4.  Настройка CI/CD (GitHub Actions).

## Этап 8: Юридическое сопровождение
*   Полёты дронов тяжелее 250 г требуют подключения к «ЭРА-ГЛОНАСС».
*   Воздушное пространство H (высота до 150 м, скорость до 450 км/ч).
*   Участие в пилотном проекте Минтранса (до 5 регионов до 2027 года).

## Этап 9: Обучение персонала
*   Обучение операторов БАС, диспетчеров логистики, водителей.
*   Регламенты действий при нештатных ситуациях.
