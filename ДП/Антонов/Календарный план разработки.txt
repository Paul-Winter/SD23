Календарный план разработки
Веб-сервис агрегации онлайн-кинотеатров
Этап: Анализ и проектирование
Период 1: 11.11.2026 – 29.11.2026
Модуль единой подписки
Работа: анализ моделей подписок онлайн-кинотеатров, изучение условий партнёрских схем и API платёжных шлюзов (ЮKassa, Stripe), проектирование сценариев оформления/продления/отмены подписки.
Результат: спецификация модуля единой подписки — диаграмма сценариев, перечень тарифов, схема взаимодействия с платёжным шлюзом.
Срок: 12.11.2026 – 15.11.2026.

Модуль регистрации/авторизации
Работа: анализ требований к аутентификации (JWT, OAuth, верификация по СМС/email), проектирование потоков регистрации и восстановления доступа.
Результат: спецификация модуля аутентификации — сценарии регистрации/входа/восстановления, схема токенов.
Срок: 15.11.2026 – 16.11.2026.

Модуль каталога
Работа: анализ структуры данных API Кинопоиска, IVI, Okko, Wink; проектирование единой модели контента и связей «контент — источник — условия доступа».
Результат: модель данных каталога, ER-диаграмма, перечень полей карточки контента.
Срок: 16.11.2026 – 20.11.2026.

Модуль поиска
Работа: проектирование единого поиска по нескольким источникам, определение стратегии нормализации и ранжирования результатов.
Результат: спецификация поиска — алгоритм агрегации результатов, правила сортировки и фильтрации.
Срок: 20.11.2026 – 22.11.2026.

Бэкенд
Работа: проектирование архитектуры сервиса (слой адаптеров API, агрегация, кэширование), проектирование БД PostgreSQL, определение стека технологий.
Результат: архитектурная схема, схема БД, перечень эндпоинтов REST API, выбор технологического стека.
Срок: 22.11.2026 – 29.11.2026.
