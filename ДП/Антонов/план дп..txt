Приложение 

-Модуль регистрации/авторизации:

Возможность пользователям регистрироваться в сервисе.
Для регистрации пользователь использует адрес электронной
почты или номер телефона, который проверяется с помощью
СМС-кода от стороннего провайдера.
При регистрации пользователь указывает пароль и имя пользователя.

Возможность пользователя авторизовываться в системе.
Для авторизации по умолчанию используется email/номер
телефона и пароль. Поддерживается восстановление пароля
через поддержку и сброс по коду.

Возможность авторизации через сторонние сервисы (OAuth —
Google, VK, Яндекс) — опционально.

-Модуль каталога:

Просмотр агрегированного каталога фильмов и сериалов,
собранного из подключённых онлайн-кинотеатров.

Отображение карточки контента: постер, описание, рейтинг,
жанры, год, актёрский состав, трейлер.

Отображение доступности контента по каждому сервису
(где фильм доступен и на каких условиях — подписка/аренда/покупка).

Фильтрация по жанру, году, рейтингу, источнику, типу
(фильм/сериал), доступности по подписке.

Сортировка (по популярности, рейтингу, новизне).

-Модуль поиска:

Единый поиск по всем подключённым источникам одновременно.

Поиск по названию, актёрам, режиссёрам, жанрам.

Отображение результатов с указанием источника и доступности.

История поисковых запросов.

-Модуль личного кабинета:

Просмотр и редактирование профиля пользователя.

Раздел «Избранное» (сохранение фильмов и сериалов).

История просмотров и переходов к контенту.

Управление подпиской (просмотр статуса, продление, отмена).

Настройки уведомлений и конфиденциальности.

-Модуль единой подписки:

Просмотр доступных тарифов единой подписки.

Оформление подписки с оплатой через платёжный шлюз (тестовый режим).

Отображение списка сервисов, покрываемых подпиской.

Управление автопродлением и историей платежей.

Отображение статуса доступа к контенту каждого сервиса.

-Модуль сравнения и рекомендаций:

Сравнение доступности одного фильма на разных платформах.

Рекомендации на основе истории просмотров и избранного.

Подборки («Популярное», «Новинки», «Скоро выйдет»).

-Модуль настроек:

Настройки конфиденциальности.

Настройки приложения (тема, язык, уведомления).

Помощь и обратная связь.

Бэкенд :
Создание и настройка базы данных PostgreSQL (пользователи, подписки, платежи, контент, связи контента с источниками, избранное, история).

Разработка интеграционного слоя (адаптеров) для подключения API онлайн-кинотеатров (Кинопоиск, IVI, Okko, Wink и др.).

Реализация сервиса агрегации и нормализации данных из разных источников к единому формату.

Настройка кэширования ответов внешних API (Redis) для снижения нагрузки и обхода лимитов.

Разработка и развёртывание собственного REST API (каталог, поиск, пользователи, подписки).

Настройка WebSocket для обновления данных в реальном времени (статусы, уведомления, доступность контента).

Настройка сервиса аутентификации и авторизации (JWT, OAuth, верификация по СМС).

Интеграция с платёжным шлюзом (ЮKassa/Stripe, тестовый режим) для оформления единой подписки.

Подключение облачного S3-хранилища для медиафайлов (постеры, изображения профиля, кэш медиа).

Настройка домена и подключение его к серверу.

Настройка резервного копирования базы данных и медиафайлов.

Настройка мониторинга сервера и логирования ошибок.

Настройка обработки ошибок и ограничений внешних API (rate limiting, fallback-источники).
