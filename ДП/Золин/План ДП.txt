Приложение:
- Модуль регистрации/авторизации
	- Возможность пользователям регистрироваться в приложении.
	  Для регистрации пользователь использует номер телефона,
	  который проверяется с помощью СМС-кода от стороннего
	  провайдеры. Также, при регистрации пользователь
	  должен указать пароль, выбрать имя пользователя 
	  и уникальный тег.
	- Возможность пользователя авторизовываться в системе.
	  Для авторизации по умолчанию используется номер
	  телефона и пароль. В зависимости от выбранных
	  настроек, пользователь также может авторизоваться
	  через адрес электронной почты. При проблемах с
	  доступом к аккаунту, пользователь также может
	  обратиться в поддержку для восстановления пароля.

- Модуль профиля
	- Каждый пользователь имеет личный профиль, который
	  можно кастомизировать любыми доступными способами:
		* Изменение фона профиля (на выбор можно установить
		  цвет фона профиля, изменить градиент из двух
	  	  цветов, установить фотографию из галереи,
	  	  установить особые фоны профиля)
	  	* Изменение аватарки профиля (на выбор можно 
	  	  установить цвет аватарки профиля, загрузить
	  	  фото из галереи, сделать фото)
	  	* Изменение рамки Аватара (6 стандартных рамок 
	  	  на выбор, остальные продаются в магазине)
	  	* Изменение имени профиля, тега, онлайн-статуса
	  	* Изменение настроений пользователя (до 5 настроений
	  	  из заранее заготовленного списка) и их видимости
	  	* Изменение поля "О себе"
	  	* Изменение фотографий профиля (до 4 фотографий)

- Модуль настроек
	- Настройки конфиденциальности
	- Настройки приложения
	- Помощь

- Модуль Aura
	- Просмотр карты в режиме реального времени
	- Отображение меток пользователей в радиусе 15 к
	- Создание меток
	- Переход во временные чаты

- Модуль звонков
	- Отображение звонков
	- Возможность аудио вызова
	- Возможность видео вызова

- Модуль мессенджера
	- Возможность просматривать активные чаты
	- Возможность создания папок с чатами
	- Возможность смотреть информацию о чате
	- Возможность создавать группы/каналы

- Модуль чатов
	- Отправка текстовых сообщений
 	- Отправка вложений (голосовые сообщения, медиа, 
	  файлы, геолокация, списки, голосования, стикеры и GIF)
	- Редактирование и удаление сообщений
	- Закрепление сообщений
	- Ответы на сообщения и пересылка
	- Реакции на сообщения
	- Отображение статусов доставки и прочтения
	- Сохранение сообщений и файлов в разделе «Сохранённое»
	- Создание опросов с возможностью указать время окончания
	- Блокировка пользователей
 
Бекенд:
- Создание и настройка базы данных PostgreSQL
- Подключение облачного S3-хранилища для медиафайлов
- Настройка домена и подключение его к серверу
- Разработка и развёртывание API
- Настройка WebSocket для обмена данными в реальном времени
- Настройка резервного копирования базы данных и медиафайлов
- Настройка мониторинга сервера и логирования ошибок
- Настройка сервиса аудио- и видеозвонков
